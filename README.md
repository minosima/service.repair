# KODI リペア（service.repair）

Kodi を DLNA サーバーとして使う場合の、ライブラリ更新後に必要な後処理を自動実行する常駐型サービスアドオンです。

## 動作概要

音楽／映像ライブラリのスキャンまたはクリーンアップの完了を検知し、待機時間をおいて次を自動実行します。

1. **スマートプレイリスト（XSP）同期**：プレイリスト保存先（music / video）配下の全 `.xsp` を再帰走査し、1つずつ GUI で開くことで、DLNA クライアント側へ内容を同期させます
2. **トラック順ソートの是正**：楽曲一覧のソート方法・順序を一旦切り替えて戻すことで、表示順の異常を防ぎます
3. **データベース診断と WAL 化**：`MyMusic*.db` / `MyVideo*.db` のジャーナルモードを確認し、WAL でない場合は外部コマンド `sqlite3` で WAL へ変更します（自動変更は設定で切替可）
4. **キャッシュ作成（任意）**：texturecache.py をバックグラウンドで実行します
5. **メール通知（任意、初期状態は無効）**：完了報告と DB 診断結果を Gmail で送信します

設定画面からは、検証モードの実行、DB 修復のみの実行、texturecache.py のダウンロード・更新も行えます。

## インストール

このフォルダ（`addon.xml` のあるフォルダ）を Kodi の addons フォルダに置くか、フォルダごと zip にして「zipファイルからインストール」してください。サービス型アドオンなので、有効化すると Kodi 起動中は常駐します。

## 設定について

- 共通設定：各処理の間隔・待機時間
- データベース設定：WAL 自動変更の有無、手動 DB 修復の実行トグル
- 検証設定：検証実行トグルとループ回数
- キャッシュ設定：texturecache.py の実行有無と取得元 URL（既定は MilhouseVH 版の公開 URL）
- 通知設定（Gmail）：**配布版では送信は無効、アドレスとアプリパスワードの初期値は空です。** 使う場合は、自分の Gmail アドレスと Google アカウントで発行したアプリパスワードを設定し、送信を有効にしてください（セキュリティ上のリスク回避のため、送信専用の個人情報を極力含まないアカウントを作成してください。）

## 注意

- WAL 変更には、Kodi を動かしている OS 側で `sqlite3` コマンドが使える必要があります
- texturecache.py は外部プロジェクト（MilhouseVH）のスクリプトで、本アドオンには含まれません。設定画面から取得できます
- 個人利用を前提に公開しています
